# Изменения

## 0.3.2 — Android stability preview, 2026-10-27

- Устранён подтверждённый на Xiaomi Pad 6 ANR при перемещении по длинному списку подсказок: главный поток больше не прокручивает список в цикле с искусственными MotionEvent. Выбранная строка позиционируется за кадр.
- Исправлена публикация списков из одного–четырёх вариантов. Результаты публикуются одной порцией; устаревшее дополнение не применяется к другой версии документа.
- Подсказки, действия с текстом и диагностические окна учитывают физическую область редактора после масштабирования; окно с одним вариантом проверено при 50%, 100%, 188% и 250%.
- Стрелки вверх/вниз сохраняют желаемую визуальную колонку через короткие и пустые строки. Поддерживаются Shift, табуляция и панель над клавиатурой. Горизонтальное перемещение и ввод текста задают новую колонку.
- Автодополнение: Ctrl+Alt+Space; параметры: Ctrl+Alt+P. Оба сочетания настраиваются; одинаковые назначения отклоняются. Ctrl+Space остаётся системе.
- Это проверочная поддерживающая сборка ветки 0.3 для Android ARM64. Полная стабильность не заявляется; старый target SDK этой ветки сохраняется. Экспериментальный runtime 1.0 не входит в это исправление.

## 0.3.1 — 2026-10-20

- Масштабирование кода использует одинаковое преобразование обеих осей без смены шрифта на отпускании жеста. Размер внутреннего редактора согласован с масштабом; маска отрисовки учитывает прокрутку, устраняя обрезку справа и снизу.
- Панель консоли сохраняет положение прокрутки кода при перетаскивании. Дробный масштаб сохраняется без округления до целого процента.
- Компактные вкладки файлов и строки переменных, направляющие вложенности, дополнительное место после точек останова.
- Единое создание папок/файлов около дерева, свободные имена, встроенное переименование с выделением имени без расширения; добавление проекта из списка.
- Выборы и подсказки поверх интерфейса; открытие меню сохраняет код. Наведение мышью на действия и диагностику.
- Панель клавиатуры выполняет действие после отпускания и отменяет его при прокрутке; спокойная обратная связь и повтор стрелок при удержании.
- Ctrl Alt со стрелками/R/D/K/B/T для отладки на Android-клавиатурах. Системный Ctrl Space остаётся доступным для раскладки.
- Удаление GCC с восстановлением из APK, управление дополнительными инструментами; проверена сборка Clang после удаления GCC.
- Локальная диагностика длительных задержек без автоматической отправки данных.
- Три запускаемых CMake-примера, расширенная галерея, сравнение Android-инструментов, описание цели проекта и проверка лицензий/приватности. Дополнены уведомления зависимостей и исходники в прежних выпусках.

Сохраняются ограничения старого target SDK, первого разбора заголовков и охвата устройств. Полная совместимость с CLion не заявляется.

## 0.1.0 — 2026-10-19

Первый выпуск GCC C++ Studio для Android ARM64.

- Автономные GCC 15.2, Clang/clangd 21.1, CMake/Ninja, GDB и Git.
- Редактор Monaco с оформлением по образцу CLion Dark, семантической подсветкой, диагностикой при вводе, серыми неиспользуемыми символами, автодополнением и навигацией.
- Выбор C/C++ стандарта, сборка файла/проекта/CMake, запуск со вводом и аргументами.
- Отладка GDB: точки останова, шаги, стек, локальные переменные и выражения.
- Два редактора, изменяемые панели, независимый масштаб интерфейса и кода, сохранение расположения.
- Локальная история, импорт и экспорт проектов; публичные исходники приложения и отдельный архив исходников нативных компонентов.
