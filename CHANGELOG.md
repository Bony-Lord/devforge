# Изменения

## 0.3.7 — 2026-10-28 · Downloadable runtime preview

- GCC и CMake исключены из APK и доступны как отдельные загружаемые пакеты. Общие заголовки/библиотеки скачиваются один раз по зависимости; старые установки сохраняются.
- Мастер первого запуска поддерживает загрузку GCC/CMake, быстрый и полный выбор, ручные зависимости и пропуск установки. Редактор открывается без runtime и интернета.
- Прогресс, отмена и продолжение HTTP Range, проверка размера и SHA-256 архива и каждого файла. GCC и CMake можно удалить и установить снова независимо.
- Подробности и границы проверки: [DOWNLOADABLE-RUNTIME-0.3.7](docs/DOWNLOADABLE-RUNTIME-0.3.7.md). Нативные бинарники и target SDK28 не изменены.

## 0.3.6 — 2026-10-27 · Android keyboard/scroll preview

- Размер плавающей клавиатуры меняется за края и нижние углы, без отдельной кнопки. Заголовок перемещает клавиатуру; размеры PC- и Android-раскладок сохраняются отдельно.
- Второй палец не перехватывает растягивание и не вводит случайную букву. Отмена жеста возвращает прежние размеры.
- При показе нашей клавиатуры скрывается оставшаяся системная клавиатура, которая могла перекрывать клавиши и края.
- Редактор прокручивается ниже конца файла: при максимальной прокрутке остаётся видимой половина последней строки, в том числе после масштабирования.
- 16 целевых проверок на Xiaomi Pad 6 / Android 14. Это предварительное обновление существующей Android-ветки; target SDK28 сохранён.

## 0.3.5 — 2026-10-27 · Android input/layout preview

- Кнопка Нажатие/Удержание прямо на плавающей клавиатуре, маленькие серые обозначения символов Shift.
- Один контроллер мультитача по pointer ID: корректные сочетания при разном порядке отпускания, два Shift, отмена, повтор клавиш и защита от залипания. Удержание команды не повторяет запросы автодополнения.
- Исправлена промежуточная геометрия содержимого после анимации: штатный принудительный пересчёт Dockview по завершению и отдельная геометрия нативного редактора.
- Области привязки следуют текущим группам после перестройки. Второй палец не перехватывает активный перенос, размеры навигации/вывода сохраняются при отделении файла.
- Привязка подтверждается отпусканием; бледный предпросмотр, широкие зоны окон, автоматическое уменьшение при отделении, перенос за край с возвратом/сворачиванием. Вкладки переставляются внутри окна с анимацией.
- Повторная кнопка слева действительно скрывает окно. Исправлено восстановление размера плавающих и прикреплённых панелей. Наша клавиатура выбрана по умолчанию и вводит текст также в поля интерфейса.
- Исправлен отдельный возврат границ прикреплённых панелей после отпускания: принудительная раскладка выполняется на следующем кадре, после сохранения пропорций Dockview. Проверены реальные пальцевые жесты дерева, консоли и вложенных разделителей кода, а также сохранение размеров перед уходом в фон.
- Конфигурации запуска: список и формы по привычной схеме IDE, отдельные профили, копирование, JSON, ручные argv-команды, шаблоны C/C++ и пустого проекта. CMake File API находит реальные имена и вложенные пути программ.
- В отладке добавлены восстанавливаемые runtime warning от UBSan и опциональный ASan для Clang. Неинициализированные значения проверяются статически; полного MSan-покрытия нет. [Подробности](docs/RUN-CONFIGURATIONS-0.3.5.md).
- В план SDK добавлены универсальные типы проектов, расширения уровня модов, официальные Python и notebook-паки. SDK и маркетплейс остаются планом.
- [Методика и ограничения](docs/INPUT-LAYOUT-0.3.5.md). Это предварительное исправление target SDK28.

## 0.3.4 — 2026-10-27 · Android workspace preview

- Файлы стали настоящими вкладками окон: несколько файлов рядом, отделение/объединение переносом, несколько представлений одного файла, список вкладок и доступные действия в узком заголовке.
- Проект, поиск, структура и Git переключают одно общее окно; консоль, сборка, терминал, отладка и проблемы — другое. По умолчанию слева навигация, снизу консоль на всю ширину.
- Прямая привязка после короткой остановки у края, вставка до отпускания, плавное изменение геометрии, затухающая инерция. Перенос и изменение размера разделены; верхние захваты выключены, повторное растягивание исправлено.
- Настраиваемый упрощённый интерфейс без оконника с сохранением оконной раскладки для возврата.
- Полная плавающая PC-клавиатура по умолчанию, компактный Android-вариант, функциональные/навигационные клавиши, модификаторы, многопальцевые сочетания, Num Lock, процентные размеры для каждого варианта и выбор основной клавиатуры.
- Исправлены слои плавающего кода, меню и других окон; сохранены границы вокруг нативного редактора. Точки останова поверх номеров строк; значок отладки зелёный.
- Меньше повторной настройки редактора при переносе. При неразобранных целях CMake не показывается необоснованное предупреждение об отсутствии исходника в цели.
- Подробности, методика и ограничения: [WORKSPACE-0.3.4](docs/WORKSPACE-0.3.4.md). Это предварительная поддерживающая сборка target SDK28.

## 0.3.3 — Android workspace preview, 2026-10-27

- Одна верхняя строка, временно заменяемая меню; кнопки действий с векторными иконками и подсказками по мыши/удержанию пальца. Диалоги отменяются касанием снаружи.
- Отдельные кнопки инструментов слева. Консоль по умолчанию занимает всю ширину под проектом; перетаскивание, группировка, привязка к четырём краям, плавающие окна, размеры и сохраняемая раскладка.
- Режим фокуса Ctrl+Shift+F12, двойной щелчок по вкладке файла, разворачивание/восстановление инструментов. Вкладки больше не пересоздаются при каждом вводе.
- Встроенная плавающая RU/EN-клавиатура включается кнопкой на полосе над системной. Перемещение, размер, Shift/Caps, Ctrl/Alt, символы, повтор удаления, Tab, стрелки и clipboard.
- Анализ ждёт подтверждения нативных правок; повторяется после ресинхронизации. Форматирование сохраняет позицию, избегает пустых правок и не забирает фокус у другого файла. Остановка отладки очищает устаревшие кадры и значения.
- Различимые значки/цвета проекта, консоли, терминала, CMake, сборки, отладки и проблем; состояние процесса и счётчик ошибок.
- 74 целевые проверки на физическом Xiaomi Pad 6 / Android 14. [Методика и ограничения](docs/WORKSPACE-0.3.3.md). Предварительная ветка target SDK28; предупреждение Google Play остаётся.

## 0.3.2 — Android stability preview, 2026-10-27

- Устранён подтверждённый на Xiaomi Pad 6 ANR при перемещении по длинному списку подсказок: главный поток больше не прокручивает список в цикле с искусственными MotionEvent. Выбранная строка позиционируется за кадр.
- Исправлена публикация списков из одного–четырёх вариантов. Результаты публикуются одной порцией; устаревшее дополнение не применяется к другой версии документа.
- Подсказки, действия с текстом и диагностические окна учитывают физическую область редактора после масштабирования; окно с одним вариантом проверено при 50%, 100%, 188% и 250%.
- Стрелки вверх/вниз сохраняют желаемую визуальную колонку через короткие и пустые строки. Поддерживаются Shift, табуляция и панель над клавиатурой. Горизонтальное перемещение и ввод текста задают новую колонку.
- Автодополнение: Ctrl+Alt+Space; параметры: Ctrl+Alt+P. Оба сочетания настраиваются; одинаковые назначения отклоняются. Ctrl+Space остаётся системе.
- Это проверочная поддерживающая сборка ветки 0.3 для Android ARM64. Полная стабильность не заявляется; старый target SDK этой ветки сохраняется. Экспериментальный runtime 1.0 не входит в это исправление.

## 0.3.1 — 2026-10-20

- Масштабирование кода использует одинаковое преобразование обеих осей без смены шрифта на отпускании жеста. Размер внутреннего редактора согласован с масштабом; маска отрисовки учитывает прокрутку, устраняя обрезку справа и снизу.
- Панель консоли сохраняет положение прокрутки кода при перетаскивании. Дробный масштаб сохраняется без округления до целого процента.
- Компактные вкладки файлов и строки переменных, направляющие вложенности, дополнительное место после точек останова.
- Единое создание папок/файлов около дерева, свободные имена, встроенное переименование с выделением имени без расширения; добавление проекта из списка.
- Выборы и подсказки поверх интерфейса; открытие меню сохраняет код. Наведение мышью на действия и диагностику.
- Панель клавиатуры выполняет действие после отпускания и отменяет его при прокрутке; спокойная обратная связь и повтор стрелок при удержании.
- Ctrl Alt со стрелками/R/D/K/B/T для отладки на Android-клавиатурах. Системный Ctrl Space остаётся доступным для раскладки.
- Удаление GCC с восстановлением из APK, управление дополнительными инструментами; проверена сборка Clang после удаления GCC.
- Локальная диагностика длительных задержек без автоматической отправки данных.
- Три запускаемых CMake-примера, расширенная галерея, сравнение Android-инструментов, описание цели проекта и проверка лицензий/приватности. Дополнены уведомления зависимостей и исходники в прежних выпусках.

Сохраняются ограничения старого target SDK, первого разбора заголовков и охвата устройств. Полная совместимость с CLion не заявляется.

## 0.1.0 — 2026-10-19

Первый выпуск GCC C++ Studio для Android ARM64.

- Автономные GCC 15.2, Clang/clangd 21.1, CMake/Ninja, GDB и Git.
- Редактор Monaco с оформлением по образцу CLion Dark, семантической подсветкой, диагностикой при вводе, серыми неиспользуемыми символами, автодополнением и навигацией.
- Выбор C/C++ стандарта, сборка файла/проекта/CMake, запуск со вводом и аргументами.
- Отладка GDB: точки останова, шаги, стек, локальные переменные и выражения.
- Два редактора, изменяемые панели, независимый масштаб интерфейса и кода, сохранение расположения.
- Локальная история, импорт и экспорт проектов; публичные исходники приложения и отдельный архив исходников нативных компонентов.
