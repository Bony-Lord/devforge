# Изменения

## 0.5.0-alpha.2 — 2026-10-28 · одно окружение вместо отдельных APK

- Modern host уменьшен примерно с 231 до 9,3 МБ. Нативные образы вынесены в одно общее окружение около 179 МБ; данные выбранных инструментов загружаются как `.studio-toolpack`.
- Установка/обновление окружения требует одного системного подтверждения. Добавление и удаление отдельных инструментов больше не запускает установщик Android. Редактор без инструментов не скачивает окружение.
- Импорт официального окружения/пака из файла, проверка подписей и контрольных сумм, отдельное удаление окружения. Несовместимый пакет не мешает запуску редактора.
- Исправлен запуск современного GDB: точки в пользовательской программе становятся отложенными до её загрузки. Отладка готового исполняемого файла сохраняет прежний вывод сборки.
- Установка и 32 проверки нового окружения выполнены на Xiaomi Pad 6 / Android14; отдельно проверены установка, отмена, удаление, перезапуск и несовместимое окружение на API36-эмуляторе. Версия остаётся предварительной. [Доставка и ограничения](docs/MODULAR-RUNTIME-0.5.md).

## 0.5.0-alpha.1 — 2026-10-28 · несколько языков и платформ

- Отдельные составы аддонов и раскладки проектов, наследование общего набора, профили CMake / интерпретатора / ручного запуска. Провайдеры действий сборки, запуска и отладки; незаданные действия скрывают кнопки и команды.
- `.devforge/project.json` с чтением прежних конфигураций; создание нового проекта завершается до смены его интерфейса. Отменяемая ручная сборка с cwd/env и остановкой после ошибки.
- Исправлены гонка первого снимка Android-редактора при редактировании notebook, нулевая высота области ячеек, очистка закрытых представлений и запоздавшая остановка чужого ядра. Современные программы Clang явно подключают UBSan; ASan для hosted-программ пока недоступен.

- Официальные паки Python и Python/ноутбуков: проекты, запуск скриптов с аргументами/окружением и проверка синтаксиса без исполнения.
- `.ipynb` как документ в области редактора, без модального окна. Ячейки code/Markdown/raw, перемещение, вывод, traceback, Shift+Enter, общее состояние Python-ядра и его перезапуск. Round trip сохраняет метаданные, вложения и существующие rich outputs.
- Modern Android target36: установленный нативный хост, packaged runtime и запуск shared program, SDK36 Back dispatcher, системные insets. Compat target28 сохранён отдельно.
- Настольный backend подключён к актуальным аддонам/доверию папке/редактору документов; Python и модель notebook общие с Android. Проверки переносимого backend для Windows/Linux/macOS в CI.
- Реальный C++/Python backend Windows, реальное выполнение Python/GCC/Clang/CMake в Android16 эмуляторе и интерфейс проверяются на отдельных данных. Это alpha, без заявления о стабильности/полноте. [Подробности и ограничения](docs/PYTHON-NOTEBOOKS-PREVIEW.md).
