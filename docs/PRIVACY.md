# Данные и разрешения

DevForge (прежнее имя C++ Studio) хранит проекты, настройки, историю и установленный runtime на устройстве. Анализ, компиляция, форматирование и отладка выполняются локально. Рекламные и аналитические SDK не включены.

- **Файлы:** приватные проекты находятся в данных приложения. Открытие папки устройства работает с её оригиналами, импорт — с копией. Широкое разрешение файловой системы запрашивается для работы с обычной структурой проектов. Системный Files получает доступ через DocumentsProvider и предоставленные Android права.
- **Сеть:** загрузка выбранных инструментов обращается к GitHub Releases; Git использует введённый пользователем адрес. Эти сервисы получают обычные сетевые сведения запроса, например IP-адрес. Открытие GitHub Issues или справочных ссылок передаётся внешнему приложению.
- **Сторонние аддоны:** загрузка по введённой HTTPS-ссылке обращается к выбранному серверу и его HTTPS-перенаправлениям. До согласия пакет не устанавливается. Источник, хеш содержимого и подтверждение установки сохраняются в приватной библиотеке приложения. Текущий загрузчик принимает пакеты данных, а не исполняемые сторонние моды.
- **Доверие проекту:** решение хранится в приватных настройках для точного пути папки. Оно не отправляется разработчику. Разрешённые команды проекта имеют доступ приложения к файлам; режим доверия не является изоляцией уже доверенного кода средствами ОС.
- **Сообщение об ошибке:** форма GitHub получает версию приложения, модель устройства и версию Android. Она не публикуется автоматически. Код, файлы и журналы не прикрепляются автоматически.
- **Локальная диагностика:** в памяти текущего сеанса сохраняются до 16 записей длительных задержек интерфейса и стеки Java. Текст кода, имена файлов и клавиши туда не записываются. Просмотр доступен через «Вид → Диагностика отзывчивости»; журнал не отправляется разработчику.
- **Экран:** настройка удержания экрана действует во время работы с IDE.
- **Удаление:** удаление приложения стирает его приватные данные средствами Android. Общие папки устройства остаются на своих местах. Перед удалением сохраните или экспортируйте приватные проекты.

Код проекта открыт. При добавлении новых сетевых функций или SDK этот документ должен быть обновлён. Политики GitHub и других выбранных сервисов действуют на их стороне.
