# Платформы и механизм запуска

Кандидат **1.0.0-rc.1** поддерживает Android ARM64, Windows x64, Linux x64 и macOS ARM64. Это предварительный выпуск; физическая проверка нового Android runtime ещё требуется. Предыдущий 0.3.1 остаётся доступен отдельно.

| Платформа | Механизм | Проверка |
|---|---|---|
| Android 9+ ARM64 | API 36, инструменты устанавливаются PackageManager; собственный хост загружает собранную shared-программу | Реальная цепочка GCC/Clang/CMake/GDB/ASan на Android 16 x86_64 в эмуляторе; ARM64 ELF проверены на 16 KB, новое физическое устройство не проверялось |
| Windows x64 | Electron/Monaco, системные GCC/Clang, CMake/Ninja, GDB + gdbserver | Локальные сборка/ввод/файлы/отладчик и настоящее окно приложения; дополнительно CI |
| Linux x64 | Electron/Monaco, системные инструменты, GDB или LLDB DAP | CI, включая настоящий LLDB и окно приложения через Xvfb |
| macOS ARM64 | Electron/Monaco, Xcode/Homebrew, LLDB DAP | CI на macos-latest; только ad-hoc подпись, без notarization |

## Современный Android

В 1.0 основной вариант использует `targetSdk 36`. Исполняемые инструменты находятся в установленном Android каталоге нативных библиотек, а пользовательская программа загружается отдельным установленным процессом. GCC, его дочерние программы, CMake/Ninja, stdin, GDB и ASan проверяются целиком. Подробности: [MODERN-ANDROID.md](MODERN-ANDROID.md).

Скомпилированная программа запускается с **корнем проекта** как рабочей папкой. Обычные CMakeLists.txt и src/include/data сохраняются. Бинарные библиотеки для Windows/Linux необходимо пересобрать под Android; одинаковая структура проекта не делает любые desktop-зависимости переносимыми автоматически.

Вариант `compat` с target 28 оставлен для регрессионной проверки. В 0.3.1 предупреждение о старом target оставалось; в 1.0 причина старого target устранена новым backend. Это не гарантия отсутствия всех предупреждений установщика или Play Protect.

Основной APK включает полный набор нативных инструментов. Их отключение не уменьшает установленный APK. AAB переносит данные в install-time asset pack. Опциональная доставка нативных модулей через Play Feature Delivery пока не реализована.

Для публикации в Play недостаточно API 36: требуется отдельная проверка приложения магазином и декларация широкого доступа к файлам. Они не выполнены. Системные проверки безопасности не отключаются. [Требование target API](https://developer.android.com/google/play/requirements/target-sdk) · [Доступ ко всем файлам](https://support.google.com/googleplay/android-developer/answer/10467955).

## Настольные версии

Компиляторы устанавливаются менеджером пакетов ОС и обнаруживаются автоматически либо указываются в настройках. CMake использует Ninja, чтобы одинаково обрабатывать пути с пробелами и кириллицей. Проекты находятся в обычных папках, поддерживаются кодировки/BOM, история и защита от перезаписи внешних изменений. [Установка и сборка](DESKTOP.md).

Публичной подписи издателя Windows и Apple notarization нет. Поддержка ОС означает рабочую реализацию и указанные автоматизированные проверки, а не проверку всех клавиатур, IME, жестов, оконных менеджеров и устройств.
