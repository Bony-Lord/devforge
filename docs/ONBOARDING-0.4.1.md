# Первый запуск и языковые модули — Android 0.4.1 preview

Новое название приложения — **DevForge**. Мастер и менеджер используют общую модель выбора: включённый, частичный и выключенный пак. [Менеджер, согласие и доверие](DEVFORGE.md).

Мастер первого запуска собирает профиль из каталога аддонов. Он больше не содержит собственный список версий C/C++, компиляторов или форматтеров.

1. Выбор языка интерфейса и состава: ядро, удобный минимум, полная C++ IDE либо ручная сборка.
2. Просмотр возможностей, автоматически включённых зависимостей и изменение состава.
3. Параметры выбранных модулей: клавиатура, отступы, языковые стандарты, форматтер. У ядра остаются масштаб интерфейса и удержание экрана.
4. Просмотр состава и размера недостающих native-загрузок, затем применение.

Удобный минимум рекомендуется по умолчанию и работает без скачивания native-инструментов. Уже установленные инструменты повторно не скачиваются. При ошибке установки выбор остаётся доступен для повторной попытки; шаг, язык интерфейса и параметры сохраняются между запусками. Закрытие мастера сохраняет ранее активный состав. Существующие проекты не форматируются этим мастером.

Клавиатура редактора разрешается после восстановления интерфейса и завершения мастера. Это устраняет воспроизведённую вспышку примерно на 250 мс до появления первого диалога. Галочки, переключатели и списки больше не считаются текстовыми полями. Настоящие поля ввода продолжают открывать клавиатуру по касанию.

## Границы между ядром и языками

- `setup-model.js` — переносимый планировщик состава и проверка значений, без DOM, Android и знаний C/C++.
- `addons/compositions.json` — описания готовых составов.
- `setupFields → settings.fields` — поля от выбранных официальных модулей. Языковой модуль C/C++ владеет своими стандартами, форматтер — стилями, клавиатура — раскладками.
- Языковые правила предоставляют расширения, имена файлов и необязательные `entryFiles` для начального открытия документа. Общий код восстановления больше не ищет исключительно `main.cpp` или `main.c`.

Добавление тестового Python/notebook-провайдера проверяет расширяемость контрактов. **Это не реализованная поддержка Python/ipynb.** Существующие C++ build/debug/LSP-адаптеры ещё предстоит привести к универсальным контрактам. Сторонние пакеты данных пока не могут добавлять исполняемые языковые серверы или произвольные поля мастера; поля предоставляют проверенные модули хоста.

## Проверка

На Xiaomi Pad 6 / Android 14 проверяются холодные запуски, отсутствие реально отрисованных кадров клавиатуры до мастера, базовый и полный составы, поля выбранных аддонов, фокус ввода, восстановление черновика, переключение языка и повторная попытка после имитации сбоя подготовки. Для этих сценариев сбрасывались только тестовые настройки и библиотека аддонов; пользовательские проекты и native-инструменты сохранялись. Это не повторная полная деинсталляция и не проверка всех возможных устройств.

Target SDK остаётся 28: предупреждение Play Защиты при чистой установке этим обновлением не устранено. Ограничения прежней полной проверки описаны в [отчёте 0.4.0](CLEAN-INSTALL-0.4.0.md).
