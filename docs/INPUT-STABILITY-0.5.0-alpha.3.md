# Ввод и переключение панелей — 0.5.0-alpha.3

Предварительный Android-выпуск, versionCode 19. Рекомендуемая предыдущая Android preview остаётся 0.4.2. Modern использует target SDK36; compat сохраняет target SDK28 и предупреждение о старой версии Android.

Скрытая вкладка notebook больше не рисуется поверх консоли и не получает фокус от своего скрытого нативного редактора. При возврате в notebook сначала фокусируется Android WebView, затем нужная ячейка. Отложенный запрос проверяет, что пользователь ещё находится в той же вкладке.

Когда выбрана наша клавиатура, поля заранее отключают запрос системного IME. Перенос фокуса между ячейками объединён в один переход. В системном режиме исходные настройки полей восстанавливаются; нашу клавиатуру можно скрыть и снова открыть нажатием на поле.

На Xiaomi Pad 6 / Android 14 прошли 33 проверки финальной debug-сборки: пять циклов настоящих ADB-нажатий по вкладкам notebook ↔ консоль, шесть переключений режимов консоли боковой панелью, повторное нажатие для закрытия, переходы между ячейками с обеими клавиатурами, отсутствие системного IME при выбранной нашей клавиатуре, ввод и Backspace событиями Android, настоящее нажатие клавиши нашей клавиатуры, переходы C++ ↔ notebook и холодный запуск.

Это проверка Android-событий клавиатуры и касаний, а не отдельная проверка физической Bluetooth-клавиатуры. На других устройствах и версиях WebView эти изменения в этом выпуске не проверялись. Полная проверка жестов, длительного набора и всех возможных зависаний остаётся впереди.

Также прошли 77 групп локальных проверок исходников, 7 проверок политики WebView-клавиатуры, 20 проверок состояния редактора/асинхронных операций, 4 проверки Python-ядра и 2 проверки установки компонентов. Обе Android-разновидности собраны, JVM-тесты и release lint завершились без ошибок. После тестов установлен подписанный обычный modern APK; исходные файлы проектов проверены, пользовательские настройки восстановлены.

Размер основного APK остаётся около 9,3 МБ. Нативное окружение и `.studio-toolpack` не изменились: используется [runtime2](https://github.com/Bony-Lord/devforge/releases/tag/v0.5.0-runtime2). Повторно устанавливать окружение ради этого исправления не требуется. Остальные ограничения Python/notebook и аддонов описаны в [документации preview](PYTHON-NOTEBOOKS-PREVIEW.md).
