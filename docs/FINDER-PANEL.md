# Панель финдеров

Откройте **OPEN-DEVFORGE-FINDERS.cmd**. Повторный запуск открывает уже работающую
панель. Она использует обычный браузер и небольшой локальный Node.js-сервис.
Дополнительные пакеты для панели не устанавливаются.

Панель сама находит общий финдер, VSX-финдер и папки проверок внутри
`%USERPROFILE%\DevForgeTests`. Другие папки можно подключить кнопкой «Папка отчётов».

## Наблюдение

- «Активные» — состояние запусков, действия, проверки, находки, текущие потоки,
  память и время до завершения. График памяти собирается, пока открыта панель.
- «История» — законченные и прерванные запуски с сохранёнными отчётами.
- «Находки» — поиск и фильтры по запуску, типу и отметке. Одинаковые причины
  группируются внутри папки проверки.

Карточка находки показывает исходный снимок, разметку, текст ошибки и ссылки на
доказательства. Можно оставить заметку, отметить подтверждение, исправление или
ложное срабатывание. Отметки сохраняются отдельно от исходных отчётов.
«Повторить проверку» запускает replay в новом профиле, сохраняя исходные файлы.

## Запуск и управление

«Новый запуск» позволяет выбрать общий или VSX-финдер, конкретный набор проверок,
длительность, seed, приложение, режим нагрузки и лимиты ресурсов:

- обычный — последовательная проверка;
- при простое ПК — ускорение и дополнительные потоки во время простоя в рамках лимитов;
- полная мощность — работа с заданным максимальным числом потоков с учётом памяти,
  резерва для системы и места для отчётов.

Максимум поля памяти рассчитывается от общего объёма ОЗУ. Для планирования
дополнительно учитывается доступная память. Порог памяти проверяется периодически,
поэтому кратковременное превышение возможно.

Новые запуски поддерживают паузу, продолжение и изменение лимитов без пересоздания
отчёта. Планировщик при паузе завершает свои рабочие процессы штатно; при продолжении
создаёт новые. Последовательный финдер приостанавливает действия между шагами.
Ограничение времени продолжает отсчитываться во время паузы.

Старые запуски, созданные до добавления контроллера, применяют настройки через
перезапуск. Панель сообщает об этом перед применением; предыдущий отчёт остаётся
в истории. Переход последовательного запуска к параллельному режиму также требует
перезапуска.

Остановка использует штатный STOP-маркер, а не завершение посторонних процессов.
Нажатие «Стоп» может потребовать завершения текущей операции и очистки профиля.
Галочка предотвращения сна действует только во время проверки; пауза снимает
соответствующий временный запрос к Windows.

Закрытие вкладки браузера не останавливает проверки. **CLOSE-DEVFORGE-FINDERS.cmd**
закрывает только локальный сервис панели; финдеры продолжают работать.

## Данные и проверка

Настройки панели, список папок, отметки и журнал сервиса хранятся в
`%USERPROFILE%\DevForgeFinderControl`. Запуски из панели получают отдельные папки
в `%USERPROFILE%\DevForgeFinderRuns`. Профиль IDE и проекты не используются для
хранения настроек панели. Отчёты и пользовательские данные не удаляются автоматически.

Сервис слушает только `127.0.0.1`. Команды доступны по случайному адресу с проверкой
источника; файлы доказательств ограничены зарегистрированной папкой запуска.

Проверки разработчика:

```powershell
node --test desktop/tests/finder-dashboard.test.cjs
node desktop/dashboard-ui-regressions.cjs
node desktop/finder-control-regressions.cjs
```
