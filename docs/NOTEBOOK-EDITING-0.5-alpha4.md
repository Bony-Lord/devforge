# Редактор ячеек notebook — 0.5.0-alpha.4

Предварительный выпуск от 29 октября 2026 года. Android versionCode 20, modern target SDK36. Предыдущая рекомендуемая Android preview остаётся 0.4.2; серия 0.5 ещё не объявлена стабильной.

![Подсветка Python в документе notebook](screenshots/0.5-alpha4-notebook.png)

Ячейки поддерживают подсветку Python и Markdown через существующий Monaco и языковые аддоны. Отключение подсветки языка возвращает обычный текст. Тема, шрифт и масштаб кода общие с IDE; слой цвета и поле ввода прокручиваются вместе по обеим осям.

Tab выравнивает курсор до следующей позиции отступа или сдвигает выделенные строки. Shift+Tab уменьшает отступ. Учитываются настройки ширины и настоящих табов. Enter в блоке Python добавляет отступ; двоеточие внутри комментария или строки не открывает блок. Ctrl+Z, Ctrl+Shift+Z и Ctrl+Y работают в пределах ячейки, включая ввод нашей Android-клавиатурой. Ctrl+Enter выполняет ячейку, Shift+Enter выполняет и переходит дальше.

Добавление и перестановка ячеек сохраняют существующие поля, выделение и историю. Изменение одной ячейки передаёт в общую JSON-модель минимальный фрагмент, сохраняя остальные метаданные и результаты. Внешняя отмена правки JSON обновляет то же поле. Изменения read-only-документа блокируются, слишком большая вставка отклоняется с сохранением прежнего текста. Токенизируются ячейки возле видимой области; источник свыше 100 000 символов или 2 000 строк остаётся доступен для простого текстового редактирования.

Проверки выполнены в отдельных проектах:

- Xiaomi Pad 6 / Android 14: 20 сценариев новой реализации — настоящие ADB-нажатия по нашей клавиатуре и вкладкам, события клавиш Android, Python из установленного окружения, обе клавиатуры, прокрутка, изменения структуры и notebook из 350 ячеек. Отдельного нового теста физической Bluetooth-клавиатуры не было.
- Windows: браузерные сценарии Chromium и проверки исходного/готового Electron-пакета включают обычный ввод, историю, выделение, подсветку, масштаб, read-only, отклонение большой вставки, запуск Python/C++ и переключение проектов.
- Переносимые тесты отступов, Unicode, минимальных правок и истории входят в проверки исходников и матрицу Windows/Linux/macOS. Результат этих тестов не подтверждает полный GUI и установщики Linux/macOS.

Установлен обычный подписанный Android APK; оригинальные файлы проектов проверены, настройки восстановлены. Данные тестов и снимки пользовательского экрана не публикуются. Windows NSIS-установщик собирается из проверенного portable-пакета; подписи издателя у него пока нет. Системная установка этого NSIS-выпуска отдельно не проверялась.

Нативное окружение и `.studio-toolpack` остаются [runtime2](https://github.com/Bony-Lord/devforge/releases/tag/v0.5.0-runtime2). Для Android достаточно обновить основной APK; повторная установка компиляторов не требуется. Windows использует установленные системные инструменты и Python.

Полный Jupyter/IPython, Pyright, Python debugger, произвольные исполняемые сторонние аддоны и онлайн-маркетплейс ещё не реализованы. Существующие rich outputs сохраняются в файле, но вывод пока текстовый. Ограничения ядра описаны в [preview](PYTHON-NOTEBOOKS-PREVIEW.md), подробные результаты — в [машиночитаемом отчёте](verification-notebook-alpha4.json).
