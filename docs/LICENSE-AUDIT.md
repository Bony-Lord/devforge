# Проверка лицензий и происхождения

Дата: **20 октября 2026 года**. Проверены исходники приложения, зафиксированные зависимости, runtime, материалы репозитория и опубликованные выпуски. Это техническая проверка соблюдения условий распространения, а не юридическое заключение об отсутствии любых возможных претензий.

## Исправленные пробелы

Часть пакетов Termux содержит `copyright` как символическую ссылку на общий текст лицензии. Старый сборщик уведомлений учитывал обычные файлы и пропускал эти ссылки. Добавлено разрешение ссылок по точному снимку `termux-licenses`: в частности, восстановлены тексты для OpenSSL, Ninja, Android NDK и ряда GNU-пакетов. Исходные уведомления не переписаны и не заменены лицензией приложения.

У отдельного выпуска дополнительных инструментов не было соседнего архива соответствующих исходников. Он дополнен архивом тех же зафиксированных нативных компонентов; дополнение уведомлений приложено также к прежним выпускам 0.2.0 и 0.3.0. При дальнейшем распространении нужно сохранять эти материалы рядом с бинарными файлами, а не ссылаться только на чужой репозиторий.

## Как повторить

```sh
python tools/check_licenses.py
python tools/check_licenses.py --archives
python tools/extract_package_notices.py --cache /path/to/verified/debs
python tools/package_notices.py
python tools/package_sources.py native-corresponding-sources.zip
```

Первый режим проверяет опубликованный инвентарь, notices, списки исходников и шрифты. Второй дополнительно читает локальные исходные архивы и проверяет их байты; их нужно получить через `prepare_sources.py`. Проверка не заменяет проверку соответствия конкретного release APK его исходникам и приложенным архивам.

## Правовые и платформенные границы

Упоминание CLion описывает ориентир и сравнение. **JetBrains и CLion — товарные знаки JetBrains s.r.o.** Связь, официальное одобрение или совместимость со всеми функциями CLion не заявляются. См. [правила JetBrains](https://www.jetbrains.com/company/brand/). Поиск по международным реестрам товарных знаков для имени C++ Studio, патентный поиск и оценка сходства оформления по конкретной юрисдикции не проводились. Полноценная clean-room процедура с независимыми командами не заявляется.

Распространение GPL-бинарников требует предоставления соответствующих исходников; библиотечная лицензия LGPL сохраняет возможность модификации и пересборки. Основание: [GPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#UnchangedJustBinary), [LGPL и перелинковка](https://www.gnu.org/licenses/gpl-faq.en.html#LGPLStaticVsDynamic), [LGPL 2.1, раздел 6](https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html). Условия компонентов продолжают действовать при любом форке проекта.

**Сборка не готова к публикации в Google Play:** `targetSdk 28` ниже действующих требований, а широкое разрешение доступа к файлам потребует отдельного обоснования/переработки. Прямой запуск скомпилированных программ пока зависит от старого target SDK. См. [требования Play](https://developer.android.com/google/play/requirements/target-sdk), [доступ ко всем файлам](https://support.google.com/googleplay/android-developer/answer/10467955) и [PLATFORMS.md](PLATFORMS.md). Это не устранено добавлением лицензий.

Не проверялись применимость законов каждой страны, экспортные ограничения для конкретного способа распространения, права на будущие пользовательские материалы и соответствие будущим правилам магазинов. Любое добавление зависимости, бренда, сетевого сервиса или новой платформы требует повторной проверки.
