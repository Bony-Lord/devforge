# Загружаемые инструменты · Android 0.3.7 preview

APK содержит редактор и интерфейс. GCC, CMake, заголовки и библиотеки C/C++ устанавливаются отдельно из мастера первого запуска или раздела «Инструменты». Мастер можно пропустить и установить компоненты позже. После установки инструментов сборка работает без интернета.

| Компонент | Загрузка | Зависимости |
| --- | ---: | --- |
| GCC 15.2 | 63,8 МБ | Общие библиотеки C/C++ |
| CMake, Ninja и Make | 8,4 МБ | Общие библиотеки C/C++ |
| Общие библиотеки, заголовки и линковщик | 28,4 МБ | — |

Общая часть устанавливается один раз. GCC и CMake можно удалять независимо друг от друга. Общие библиотеки защищены от удаления, пока нужны установленным инструментам. Существующие инструменты предыдущей версии распознаются без повторной загрузки; проекты и настройки хранятся отдельно.

Загрузка показывает размер и прогресс, поддерживает остановку и продолжение через HTTP Range. Если сервер отдаёт полный файл вместо Range, клиент начинает файл заново. До распаковки проверяются полный размер и SHA-256 архива, при распаковке — пути и SHA-256 каждого файла. Прерванная установка не считается завершённой. Неуспешная загрузка оставляет частичный архив для следующей попытки; несовпадение SHA-256 удаляет повреждённый архив.

Пакеты доступны в [v0.3.7-toolpacks](https://github.com/Bony-Lord/gcc-cpp-studio/releases/tag/v0.3.7-toolpacks); четыре прежних дополнительных пакета clangd/форматтера, Clang, GDB и Git остаются в v0.3.0-toolpacks. Подписанный APK содержит фиксированные размеры, SHA-256 и адреса пакетов. Изменение каталога требует новой сборки APK.

## Проверка

Холодный запуск проверяется с отдельным пустым runtime и собственным тестовым проектом. Общая библиотечная ZIP загодя помещается через ADB; CMake действительно скачивается по HTTPS. Для GCC проверяются настоящая отмена сетевой загрузки и HTTP Range с префиксом, помещённым через ADB. Это сокращает повторный сетевой трафик, сохраняя проверку полного архива и всех извлечённых файлов. Проверяются C17, C++20, bits/stdc++.h, исполнение, CMake/Ninja, зависимости, удаление/повторная установка и русский/английский интерфейс. Отдельный настоящий HTTP-сервер на компьютере проверяет 11 сценариев загрузчика, включая неправильный Range, повреждение, неполный ответ и отмену.

Ограничение существующей связки GCC/GNU ld: LTO с отладочными данными в проверке даёт `corrupt symbol table`. LTO проверено с `-flto -g0`. Нативные бинарники не изменены этим выпуском; полного аудита всех флагов компилятора и всех дополнительных инструментов не проводилось. Target SDK28 сохранён. SDK аддонов и маркетплейс остаются планом.

## Воспроизведение пакетов

`tools/split_base_packs.py` принимает прежний проверенный `runtime-base.zip`, выделяет GCC, CMake/Ninja/Make и оставшиеся общие файлы. Каждый исходный файл принадлежит ровно одному из трёх пакетов; содержимое сверяется с прежним manifest SHA-256. Нативный код не изменяется. Исходный архив можно извлечь как `assets/runtime.zip` из APK0.3.6 или получить через `prepare_runtime.py` → `split_runtime.py`.

```sh
python tools/split_base_packs.py --input work/tool-packs/runtime-base.zip --output work/downloadable-packs
```

Для обычной сборки редактора подготовка runtime больше не нужна. Gradle копирует ресурсы в отдельную папку сборки с явным исключением `runtime.zip`. При изготовлении финального APK удаляется прежний выходной APK: инкрементальный упаковщик может сохранить неиспользуемое место от удалённого большого ZIP. Проверка финального файла контролирует и отсутствие runtime в ZIP, и фактический размер APK.

Все нативные файлы соответствуют прежним [исходникам 0.3.2](https://github.com/Bony-Lord/gcc-cpp-studio/releases/download/v0.3.2/native-corresponding-sources-0.3.2.zip), SHA-256 `b4e9bbb41c200e3fad808ad2c5710b0a2a51f44abcb26e7307a001aae454dcab`. Лицензии, рецепты и инструкции сборки сохранены.
