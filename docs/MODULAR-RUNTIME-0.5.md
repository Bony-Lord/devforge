# Нативные компоненты Android 0.5

В `0.5.0-alpha.1` modern APK вырос примерно до 231 МБ: подготовленные GCC, CMake, Python, GDB и другие инструменты находились внутри основного APK. Выключение аддона меняло доступные функции, но не уменьшало установочный файл.

В `0.5.0-alpha.2` modern host занимает около **9,3 МБ**. В нём остаются интерфейс, редактор, API аддонов и небольшой установленный хост выполнения. **Одно общее нативное окружение**, около **179 МБ** для ARM64, устанавливается Android один раз. Выбранные данные инструментов распространяются в собственном формате `.studio-toolpack` и не вызывают системных окон установки:

| Компонент ARM64 | Загрузка, МБ | Назначение |
|---|---:|---|
| platform | 17,5 | Общие заголовки и данные библиотек |
| gcc | 7,3 | Заголовки и данные GCC / стандартной библиотеки |
| cmake | 4,2 | Модули CMake, CTest, CPack |
| analysis | <0,001 | Включение clangd и clang-format из окружения |
| clang | <0,001 | Включение Clang из окружения |
| debugger | 11,2 | Визуализаторы и данные GDB, использует отдельный Python |
| git | 0,2 | Данные Git |
| python | 3,5 | Стандартная библиотека Python |

Размеры округлены в десятичных МБ; зависимости увеличивают итог выбранного набора. Общее окружение содержит нативные образы всех нынешних инструментов, поэтому даже для одного Python требуется его загрузка. Это компромисс ради одной системной установки. Данные устанавливаются только для выбранного состава; редактор без инструментов не требует окружения. Уже установленные инструменты работают автономно. `compat` сохраняет старую ZIP-доставку и target28.

## Установка и удаление

Мастер и менеджер аддонов рассчитывают зависимости. Если окружения ещё нет, скачивается один APK и передаётся системному установщику Android. Нужны обычное разрешение «Установка неизвестных приложений» для DevForge и подтверждение Android. Системная проверка нового приложения Google Play также может появиться. Обновление самого нативного окружения снова потребует подтверждения. Добавление паков к уже установленному совместимому окружению не создаёт новых APK-сессий.

Хост проверяет зафиксированные размер и SHA256 APK/паков, идентификатор пакета окружения, версию, ABI, подпись и хеш манифеста содержимого. Официальный APK или `.studio-toolpack` можно также выбрать через файловый диалог менеджера. Эта функция принимает только совместимые официальные компоненты и не является загрузчиком произвольных нативных модов. Сторонние аддоны используют отдельный уже существующий формат `.studio-addon`.

Удаление отдельного инструмента очищает его данные и ссылки без системного запроса. Общее окружение можно удалить отдельно через «Дополнительно» в менеджере; это обычное системное удаление одного APK. Сначала нужно отключить зависимые аддоны. Несовместимое окружение не блокирует запуск редактора. При переходе со старой доставки мастер предлагает один раз установить выбранные инструменты заново; проекты сохраняются.

## Архитектура и ограничения

Исполняемые образы устанавливаются PackageManager в неизменяемые каталоги. В приватном `usr` находятся данные и ссылки на эти образы. Сгенерированная C/C++-программа запускается через установленный программный хост. Основной modern APK имеет target36; повышение target само по себе не решает ограничение исполнения writable-файлов Android.

Разделение касается нативных инструментов. Реализации оконника, клавиатуры и текущих визуальных аддонов ещё входят в хост. Произвольные исполняемые сторонние аддоны, Pyright, полный Jupyter/IPython и полноценная поддержка всех платформ остаются отдельными этапами. Эта версия пока имеет статус alpha; рекомендуемая предыдущая Android preview — [0.4.2](https://github.com/Bony-Lord/devforge/releases/tag/v0.4.2).

Пакеты привязаны к конкретному каталогу в основном APK. Публикуемые файлы `v0.5.0-runtime2` должны точно совпадать с этим каталогом; при изменении пакета нужен новый набор и обновление хоста. Генерация и ключи описаны в [BUILDING.md](BUILDING.md). Первый прототип с восемью отдельными APK отменён после проверки на Xiaomi: он требовал повторных подтверждений и застрял на системной проверке. Его положительные тесты не считаются проверками новой схемы.
