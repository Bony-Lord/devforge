# DevForge

DevForge — новое имя C++ Studio. Среда строится из языковых паков, инструментов и модулей интерфейса. Сейчас рабочая языковая специализация — C/C++; Python и notebook/IPython остаются следующим этапом.

## Выбор компонентов

Менеджер и первый запуск используют две вкладки: «Паки» и «Компоненты и инструменты». Галочка включает весь пак или группу, прочерк означает частичный состав. Отдельные компоненты находятся в раскрываемых группах второй вкладки. Галочки обновляют список на месте, сохраняя раскрытие и прокрутку. Необходимые зависимости выбираются автоматически. Отключение зависимости убирает требующие её компоненты, что видно в плане перед применением.

Есть поиск, фильтр выбранного, группа инструментов и экспорт состава. При поиске групповая галочка выбирает найденные строки. Галочки меняют план; загрузка и активация начинаются по кнопке «Применить». До этого изменения можно отменить. При сбое план сохраняется для повторной попытки. Отключение аддона и удаление скачанных файлов инструмента — разные действия. В первом запуске настройки вынесены на следующий необязательный шаг; черновик восстанавливается после перезапуска.

Это схема выбора компонентов. Модель проектов, конфигурации запуска, CMake-профили и отладка сохраняют направление CLion; языковые паки должны предоставлять специализацию через общие контракты. Онлайн-маркетплейс и произвольные исполняемые сторонние моды пока не реализованы.

## Сторонние пакеты и согласие

`.studio-addon` можно открыть из файла через Android SAF или загрузить по прямой HTTPS-ссылке. Максимальный размер — 256 КиБ; перенаправления остаются HTTPS. Можно задать ожидаемый SHA-256. Загрузка не устанавливает пакет: сначала показываются источник, автор, лицензия, возможности, зависимости и требуемые инструменты.

Для стороннего пакета нужно отметить согласие с условиями установки. Оно относится к показанным возможностям и зависимостям; Android-часть тоже отклоняет установку без этого подтверждения. В библиотеке сохраняются источник, хеш содержимого и факт согласия. Хеш проверяет целостность, но не подтверждает личность автора. Удаление и откат версий остаются доступны в менеджере.

Текущий формат содержит цвета, разрешённые команды интерфейса и зависимости. Скрипты, DEX и произвольный native-код этим загрузчиком не исполняются. Новые расширения API для языковых серверов, run/debug-провайдеров, notebook и модификаций поведения описаны в [плане архитектуры](ADDONS-ROADMAP.md).

## Доверие проекту

Незнакомая существующая папка открывается в ограниченном режиме. Можно читать и редактировать файлы; сборка, запуск, отладка, терминал, Git и запуск анализа требуют доверия. Ограничение проверяется в Android-части приложения, включая прямые запросы к bridge.

Нажмите статус доверия возле пути файла, чтобы разрешить работу с этой папкой или отозвать разрешение. При отзыве останавливаются анализ и выполняемые процессы. Решение сохраняется на устройстве для точного канонического пути; доверие родительской папке автоматически не выдаётся. Проекты, созданные самим приложением, доверенные по умолчанию. Установка аддона не выдаёт доверие папке.

## Совместимость и проверка

Идентификатор Android-приложения, подпись APK, прежние каталоги проектов и формат `.studio-addon` сохранены. Переименование не требует удаления приложения. Старые внутренние имена файлов, `.cpp-studio` и идентификаторы API остаются ради совместимости. Старые выпущенные пакеты сохраняют исходные метаданные и хеши.

Проверки 0.4.2 описаны в [машиночитаемом отчёте](../verification-devforge-042.json) и [отчёте первого запуска](ONBOARDING-0.4.2.md): 46 сценариев интерфейса в отдельном эмуляторе, без пробуждения физического планшета. Предыдущие проверки 0.4.1 на Xiaomi Pad 6 / Android 14 сохранены в [отчёте](../verification-devforge-041.json). Это целевые проверки, а не гарантия отсутствия всех ошибок. Target SDK28 и предупреждение Play Защиты при чистой установке пока сохраняются.
