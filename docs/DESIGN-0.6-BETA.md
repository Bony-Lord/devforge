# DevForge 0.6.0-beta.1

Предварительная версия для обратной связи. Стабильность всех устройств и
сценариев не подтверждена. Предыдущая рекомендуемая Android preview —
[0.4.2](https://github.com/Bony-Lord/devforge/releases/tag/v0.4.2).
Проверенной стабильной настольной версии пока нет.

## Рабочее место

Введена общая палитра: тёмно-синий редактор, отдельные поверхности панелей,
голубой акцент навигации, зелёный запуск, жёлтая сборка, красная остановка.
Вкладки, формы, меню, магазин и notebook используют одни цвета и состояния.
Светлая тема сохранена. Масштабирование больше не возвращает старую серую тему.

Слева — проект, по центру — переход к файлу, справа — конфигурация и действия.
Поиск в заголовке скрывается на узком экране; Ctrl+P остаётся доступным.
Кнопки сохранения, отмены, повтора, документации и форматирования видны над кодом.
Панель активности получила подписи и различимые векторные значки.
В настройках — категории и поиск вместо длинного общего списка.
Анимации короткие; учитываются системный reduced motion и отключение аддона.

Расположение изучено в установленном CLion и веб-версии VS Code. Использованы
общие принципы и собственные стили/значки DevForge, закрытый код не копировался.
Ориентиры: [CLion New UI](https://www.jetbrains.com/help/clion/new-ui.html),
[VS Code UI](https://code.visualstudio.com/docs/editing/getting-started/userinterface).

## Документация Python и notebook

Установите и включите дополнение **Jedi · анализ Python** и выберите
интерпретатор проекта. Пак качества Python/notebook включает эту специализацию.
Папке проекта нужно доверять, чтобы IDE запускала локальные инструменты.

- В `.py` наведите мышь на функцию или нажмите Ctrl+Q.
- В notebook наведите мышь на имя, нажмите Ctrl+Q или значок книги у ячейки.
- Показаны сигнатура, полное имя, описание и разделы docstring.
- При вводе вызова подсказка параметров подчёркивает текущий аргумент.
- Escape/кнопка закрытия убирают закреплённую подсказку. Изменение кода,
  файла, проекта или интерпретатора отменяет устаревший запрос.

Анализ статический: пользовательские ячейки ради подсказки не исполняются.
Предыдущие кодовые ячейки входят в контекст. HTML из docstring отображается
текстом. Динамические объекты и состояние уже исполнявшегося ядра могут отличаться
от статического вывода Jedi; это не полноценный Jupyter language server.
Основа: [Jedi API](https://jedi.readthedocs.io/en/latest/docs/api.html).

## Платформы и размер

Windows x64 — NSIS-установщик. Основной размер занимает Electron/Chromium;
компиляторы, Python, Jedi, PEP 8 и движок окон скачиваются отдельно либо
используются из системы. Основной пакет не содержит GCC, CMake или pandas.
Используемый Python задаётся конфигурацией проекта, а не случайным `pip` из PATH.

Android ARM64 modern — target SDK36, Android 9+. Для локального нативного
окружения может понадобиться одно системное подтверждение установки.
Compat — target SDK28 для старого пути запуска; системное предупреждение о
старом target SDK у compat остаётся. Две версии используют один application ID,
одновременно установить их нельзя.

В этой бете не выполнена физическая проверка Android, установщиков Linux/macOS
и всех Bluetooth/IME-комбинаций. Их поддержка не объявляется проверенной.
Сторонний формат дополнений пока принимает данные, темы, команды из разрешённого
набора и шаблоны; произвольные исполняемые моды и публичный сервер магазина ещё
не реализованы. [Подробности notebook и ограничений ресурсов](WORKSPACE-MARKETPLACE.md).

## Проверки

Сценарии Electron работают в изолированных временных проектах: создание без
Preview, подключение шаблона, панели в двух режимах, два окна проектов,
магазин, сохранение/восстановление, реальный ввод notebook, hover/Ctrl+Q,
параметры, категории настроек и доступность команд на ширинах 1360/800/390.
Дополнительно выполняются тесты моделей, локальных процессов и Android JVM/lint.
Точные результаты находятся в `verification.json` рядом с файлами выпуска.
Наличие автотестов не означает проверку всех взаимодействий на настоящем планшете.

Перед экспериментами с пользовательскими данными сохраняйте проекты и настройки.
Резервная копия, сделанная перед этой переработкой, хранится локально и не
включается в публичные архивы или GitHub.
