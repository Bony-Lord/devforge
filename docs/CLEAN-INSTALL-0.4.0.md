# Полное удаление и чистая установка 0.4.0

Проверено на Xiaomi Pad 6 / Android 14. Полное удаление действительно выполнялось; это отдельная проверка, не обновление поверх старых данных. Перед удалением сохранены и проверены 829 824 512 байт приватных данных приложения и его внешний каталог. После теста выполнено восстановление с проверкой хешей, ссылок, режимов и времени изменения постоянных файлов; исходные проекты и настройки дополнительно сверяются перед возвратом обычной release-сборки.

## Обнаруженное ограничение установщика

Google Play Защита блокировала чистую установку с сообщением о разработке для старой версии Android. **Target SDK28 в этом выпуске сохранён; предупреждение не исправлено.** В подробностях доступно «Всё равно установить», затем защищённое подтверждение. Это окно на проверенном планшете приняло физическое нажатие владельца, но не синтетическое касание ADB.

При установке через USB MIUI дополнительно возвращала `INSTALL_FAILED_USER_RESTRICTED`. Обычная установка APK из «Файлов» прошла после подтверждения. Для этого источник «Файлы» временно получил разрешение устанавливать приложения; после установки его исходное состояние `deny` восстановлено. Общие настройки Play Защиты не отключались. Установка без участия владельца не заявляется.

Для устранения предупреждения требуется современный механизм запуска локально скомпилированных программ и повышение target SDK. Скачиваемые аддоны сами по себе это ограничение Android не устраняют.

## Что проверено с нуля

Сначала установлен и запущен **подписанный release APK**. Для глубокой автоматизированной проверки на эти же чистые данные затем поставлен вариант с разрешённой отладкой: те же исходники, assets, версия, target SDK и сертификат. Это отличие явно учитывается; тестовые API не входят в доступные функции обычной release-сборки.

15 целевых проверок прошли:

1. Android полностью удаляет пакет.
2. Подписанный APK запускается после удаления.
3. Старых проектов и скачанных инструментов нет.
4. Появляется мастер первого запуска.
5. «Удобный минимум» позволяет редактировать и сохранять без загрузки инструментов.
6. «Полная C++ IDE» загружает зависимости настоящими HTTPS-запросами.
7. Дополнительный Clang доводит набор до всех семи native-компонентов: platform, GCC, CMake, analysis, Clang, debugger и Git.
8. Свежий GCC собирает C++-исходник.
9. Полученная программа запускается и печатает ожидаемый результат.
10. Свежий CMake настраивает и собирает проект.
11. Свежий Clang собирает тот же исходник.
12. clangd инициализирует анализ проекта.
13. Git создаёт настоящий репозиторий.
14. GDB останавливает программу на исходном коде.
15. Полная установка сохраняется после холодного запуска.

GCC/LLVM/CMake/GDB/Git во время этой проверки действительно скачивались из пустого состояния; ранее установленные файлы для неё не подставлялись. Нативные файлы исходной рабочей среды восстановлены из сохранённой копии после теста.

Отдельно в этом этапе проверены модульные функции, минимальный состав, версии пакетов, откат, установка через Android SAF, экспорт состава, окна, клавиатура, анализ и отладчик. Всего — [119 целевых проверок](../verification-addons-040.json), плюс проверки Node.js, plain Java, Android unit tests и lint. Это не доказательство отсутствия всех багов и не проверка всех Android-устройств.
