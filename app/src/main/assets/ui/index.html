Экранная клавиатура

В режиме закрепления модификатор действует на следующую клавишу. Двойное нажатие или удержание закрепляет его до повторного нажатия. Одновременное удержание нескольких клавиш работает в обоих режимах. Ctrl+Space меняет язык плавающей клавиатуры; Ctrl+Alt+Space вызывает автодополнение.

100% — клавиатура полностью поверх интерфейса, 0% — окно сжимается на её высоту. Промежуточные значения задают частичное перекрытие. Курсор прокручивается в видимую область; высота самой клавиатуры задаётся в её приложении.

Проекты и файлы

«Файл → Открыть папку устройства» открывает оригиналы без копирования. Импорт создаёт отдельную копию в IDE. Рабочая папка запуска — корень проекта. Перед удалением приложения экспортируйте приватные проекты. Изменения файлов хранятся в локальной истории.

Об этой сборке

ARM64 · Android 9 и новее. Нативный редактор Sora (LGPL), Monaco для моделей и сравнений (MIT), LLVM/clangd, GNU GCC, CMake и Ninja. Исходники компонентов и лицензии поставляются рядом с APK. Закрытый код CLion не используется. JetBrains Mono — OFL-1.1.

Основные функции GDB и Git доступны в приложении. Плагины IntelliJ, полный набор рефакторингов и все инструменты настольного CLion не переносятся. Обычная вкладка терминала не является полноэкранным PTY; отладчик использует отдельный PTY для программы.
