# Примеры для C++ Studio

Все примеры написаны для этого проекта и распространяются под [MIT](../LICENSE). Подпапки — самостоятельные обычные CMake-проекты; их также можно открыть на ПК.

| Проект | Что попробовать | Ожидаемый результат |
|---|---|---|
| [console-files](console-files/main.cpp) | Чтение файла относительно корня, функции в `src/`, заголовки в `include/` | `C++ Studio: 42` |
| [debug-containers](debug-containers/main.cpp) | Структура, `vector`, `map`, `string`, `optional`, шаг в свою функцию | `Total: 30` |
| [formatting](formatting/main.cpp) | Профиль C++ Studio, ссылки, указатели и range-for | `Sum: 16` |

1. Получите репозиторий или архив примеров из Releases. Откройте **конкретную подпапку** через «Файл → Открыть папку устройства», либо импортируйте её копию в IDE.
2. В настройках проекта выберите режим **CMake**, компилятор GCC, стандарт C++20 и цель `app`. Откройте `main.cpp`, нажмите «Запустить».
3. Для отладки установите пакет GDB, для диагностики и форматирования — пакет анализа. Скачивание нужно один раз; дальнейшая работа локальная.

Для `console-files` рабочая папка должна быть именно `examples/console-files`, где лежит `data/input.txt`; C++ Studio запускает программу из корня открытого проекта. Папку `build` вручную выбирать не нужно.

В `debug-containers` поставьте точку слева от строки `const int total = ...`. После инициализации объектов раскройте `point`, `values`, `scores` и `maybe` в панели переменных. **Ctrl+Alt+→** выполняет строку, **Ctrl+Alt+↓** входит в функцию, **Ctrl+Alt+↑** возвращается из неё. F7/F8 также работают, если клавиатура передаёт их Android.

В `formatting` измените отступы и пробелы, затем нажмите кнопку форматирования или **Ctrl+Alt+L**. Файл `.clang-format` задаёт четыре пробела, `auto& value`, `auto *pointer` и пробелы вокруг `:` в range-for. C++ Studio и CLion в списке профилей — отдельные варианты.

Для проверки диагностики добавьте в любом `main` строку `missing_function();`, дождитесь ошибки и удалите её. Добавьте `int unused_value = 0;`, чтобы увидеть серую подсветку неиспользуемого имени. При первом разборе заголовков анализатору может потребоваться несколько секунд.

На ПК из подпапки примера:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/app
```

В Windows при генераторе Visual Studio исполняемый файл обычно находится в `build/Debug/app.exe`.
