# Пример аддона

`navigation/addon.json` и `activate.js` показывают формат первой версии SDK. Для тестирования автор подключает их к доверенному тестовому хосту через `StudioAddonCore.Manager`; установленная IDE пока не импортирует сторонние скрипты. Не копируйте файл в каталог проекта с ожиданием автоматического исполнения.

См. [контракты SDK, ограничения и проверку зависимостей](../../docs/ADDON-SDK.md). MIT, как основной проект.
